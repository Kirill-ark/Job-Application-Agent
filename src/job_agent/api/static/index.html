Job Application Agent

An AI agent searches current vacancies in Germany, scores them against a CV and drafts cover letters that only use facts from the CV. Nothing is sent: every letter waits for your approval.

Which CV?

Your CV text is sent to Groq, the LLM provider, to be read. It is not stored: the parsed CV stays in your browser and is used for your run only. Letters and the run are deleted after 24 hours.
